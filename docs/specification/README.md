# OPAAL 1.0 specification

[OPAAL 1.0](1.0.md) is the normative public statement of source semantics and operational invariants. It defines its conformance subjects and the meanings of `MUST`, `MUST NOT`, `SHOULD`, and `MAY`.

Reference pages explain the shipped parser, runtime, CLI, and artifact formats in lookup form. Examples and how-to guides teach their use; they do not create new syntax or authority.
