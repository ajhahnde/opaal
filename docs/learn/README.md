# Learn OPAAL

The lessons follow one path. [Getting started](getting-started.md) runs a pure
file; [the language tour](language-tour.md) adds modules, types, patterns, and
commands. [The operational model](operational-model.md) introduces project
authority and the check–plan–execute–audit sequence.
[First project](first-project.md) then walks through a task and its evidence.

You can stop after the language tour if you only need source analysis or pure
evaluation. Running an effectful task requires an explicitly selected project;
opening a source file alone never selects one.

For exact syntax and options, use the [reference](../reference/README.md).
