# How-to guides

These guides start with a job to do. For the first complete path through OPAAL,
read [Learn OPAAL](../learn/README.md).

**Source files:** [run a script](run-a-script.md),
[check source](check-source.md), and [format source](format-source.md).

**Projects:** [create a project](create-a-project.md),
[define a task](define-a-task.md),
[inspect a project or artifact](inspect-project-and-artifacts.md),
[review and execute a plan](review-and-execute-a-plan.md), and
[audit a run](audit-a-run.md).

**Controlled operations:** [run a maintained program](run-an-external-program.md),
[use the filesystem](use-filesystem-access.md),
[make an HTTP request](make-an-http-request.md), and
[pass an injected secret](use-secrets.md).

**Editor:** [configure the language server](configure-the-language-server.md).

Each guide names the relevant refusal boundary. Check the
[CLI](../reference/tooling/cli.md), [authority](../reference/operational/authority.md),
and [platform support](../reference/platform-support.md) references before
depending on an operation in automation.
