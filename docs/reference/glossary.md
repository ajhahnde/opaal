# Glossary

| Term | Meaning |
| --- | --- |
| Action | A statically named typed callable with declared effect requests. |
| Authority | Exact external grant or deny rows for a project environment or embedding context. |
| Carrier | Empty input, byte stream, one value, or value stream passed between command stages. |
| Check | Non-executing validation of source, task bindings, authority, and target verdicts. |
| Effect | A typed request such as `filesystem.read` or `process.run`; declaration is not permission. |
| Environment | A manifest name selecting exactly one authority file and tool lock. |
| Journal | Synced, hash-chained evidence of one admitted execution, including partial effects. |
| Plan | Expiring artifact binding a checked task and its control, source, host, and tool identities. |
| Project | Explicitly selected `opaal.toml` and its contained source and control files. |
| Refusal | A classified non-execution result when a required route, grant, or guarantee is absent. |
| Task | A root-module export of exactly one action with its existing signature and effects. |
| Tool lock | Exact platform, executable, version, digest, and child-environment declaration. |
| Value stream | Lazy, typed, single-consumer structured carrier. |

Use [the reference index](README.md) to follow a term to its full contract.
