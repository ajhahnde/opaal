# Reference

The [1.0 specification](../specification/1.0.md) states language semantics and operational invariants. These pages explain shipped forms, commands, modules, and files.

- [Language](language/README.md): syntax, values, modules, commands, actions, streams, and outcomes.
- [Standard modules](std/README.md): the compiled module catalog.
- [Operational model](operational/README.md): projects, authority, capabilities, inputs, and lifecycle.
- [Formats](formats/README.md): closed TOML documents and v2 artifacts.
- [Tooling](tooling/README.md): CLI, interactive client, and language server.
- [Embedding](embedding/README.md): the current Rust context and its compatibility boundary.

Use [diagnostics](diagnostics.md) to interpret a refusal, [limits](limits.md) for exact budgets, [platform support](platform-support.md) for host claims, [versioning](versioning-and-compatibility.md) for compatibility, and the [glossary](glossary.md) for cross-layer terms.
