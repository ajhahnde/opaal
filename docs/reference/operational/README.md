# Operational model reference

A project is selected by the exact path to `opaal.toml`. It declares tasks, bindings, and environments; OPAAL never searches parent directories to activate it. Check and plan read bounded control inputs without running the task. Execute accepts one exact plan digest for one request.

Read [projects and tasks](projects-and-tasks.md) for selection and exported actions, [authority](authority.md) for exact grants and denials, [inputs, tools, endpoints, and secrets](inputs-tools-endpoints-and-secrets.md) for bindings, and the [capability matrix](capability-matrix.md) for host enforcement. [Lifecycle](lifecycle.md) describes the artifact sequence and refusal points.

The [formats](../formats/README.md) section gives file shapes.
